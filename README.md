* # 🥤 Sugar Ultra (糖人App) - 极客范的奶茶手账与自律管家

  **Sugar Ultra** 是一款专为奶茶与咖啡爱好者打造的沉浸式生活记录工具。它不仅仅是一个高颜值的账单本，更是一个融合了**智能算法**、**物理微交互**与**情绪价值**的“赛博手账”。目前，项目已演进为拥有原生 App 级质感、完整业务闭环及离线优先架构的成熟单页应用 (SPA)。

  ------

  ## ✨ 核心功能特性

  ### 1. 🏆 勋章墙与成就系统 (New!)

  - **时光倒流算法**：内置智能排序逻辑，无论用户是按时记录还是事后补录，系统都会严格按真实饮用日期进行正序重排，精准定位触发成就的“那一天”。
  - **8 大荣誉勋章**：包括「初次邂逅」、「品牌死忠」（连续 20 杯）、「海王品鉴」（15 个品牌）、「清糖苦行僧」（50 杯无糖）等极具人设感的成就。
  - **SSR 高光卡片**：点击已解锁勋章，将唤起基于 `motion/react` 的居中聚焦弹窗，以“高光见证者”相框形式展示解锁成就的关键饮品及其达成日期。

  ### 2. 📅 沉浸式记录与日历墙

  - **智能品牌匹配**：内置 10 余个主流品牌（瑞幸、霸王茶姬等）的关键字匹配字典，输入简写（如“rx”）即可自动映射品牌标识与专属 UI 色彩。
  - **动态日历视图**：首页日历支持在“品牌 Logo”与“实拍贴纸”间无感切换。针对一天多杯的情况，Logo 会以动画形式自动轮播展示。

  ### 3. 📊 多维数据统计与视觉货架

  - **时光贴纸盒**：利用 `Framer Motion` 实现带有物理堆叠感的“贴纸墙”。贴纸会随记录增加自动微缩，并支持悬浮放大交互。
  - **品牌占比环图**：根据品牌属性自动分配专属色（如瑞幸蓝、蜜雪红），支持“杯数”与“花费”双维度统计切换。

  ### 4. 🧾 “电影级”分享引擎

  - **三合一分享模式**：支持“单杯精致小票”、“周期统计长单”以及“Spotify 风格 Wrapped 海报”。
  - **高清导出**：基于 `html-to-image` 的 3 倍采样率渲染，确保分享到朋友圈的每一张海报都清晰锐利，支持原生 `navigator.share` 唤起系统分享。

  ------

  ## 🛠️ 技术深度与性能优化

  ### 1. 🚀 极致渲染与性能

  - **静默图片压缩 (WebP)**：通过 HTML5 `Canvas` 在前端静默将 5MB-10MB 的原图压缩至 100KB 以内的 `WebP` 格式，在保留透明度的同时解决存储压力。
  - **空间瘦身工具**：设置页内置“空间瘦身”功能，可一键对存量 Base64 历史数据进行批量洗刷与重压缩。
  - **浮点数精度保障**：针对金额计算进行了精度修复逻辑封装，确保统计数据分毫不差。

  ### 2. 💽 离线优先架构

  - **localforage 存储**：摒弃传统的 `localStorage`，采用 `localforage` 构建底层异步数据库，支持海量图片数据的离线存储。
  - **数据孤岛救援**：提供完整的 `.json` 格式数据导出（备份）**与**导入（恢复）功能，无惧清缓存或换手机。

  ### 3. ✨ 物理级微交互

  - **触觉反馈 (Haptics)**：深度接入 `navigator.vibrate`，在点击成就、保存记录等关键节点提供三级物理震动反馈。
  - **动态字号系统**：支持“小、中、大”三档字号切换，动态修改 HTML 根元素 `font-size`，全局驱动 Tailwind 响应式布局。

  ------

  ## 💻 技术栈

  - **核心框架**: Next.js 14+ (React 18+)
  - **样式方案**: TailwindCSS
  - **动画引擎**: motion/react (Framer Motion)
  - **数据持久化**: localforage
  - **截图引擎**: html-to-image
  - **图标库**: Lucide React
