* - # 🥤 Sugar Ultra (糖人App) - 极客范的奶茶手账与自律管家

    **Sugar Ultra** 是一款专为奶茶与咖啡爱好者打造的沉浸式生活记录工具。它不仅仅是一个高颜值的账单本，更是一个融合了**智能算法**、**物理微交互**与**情绪价值**的“赛博手账”。目前，项目已演进为拥有原生 App 级极致交互体验、完整业务闭环及离线优先架构的成熟单页应用 (SPA)。

    ---

    ## ✨ 核心功能特性

    ### 1. 🏆 勋章墙与成就系统 (New!)

    - **时光倒流算法**：内置智能排序逻辑，无论用户是按时记录还是事后补录，系统都会严格按真实饮用日期进行正序重排，精准定位触发成就的“那一天”。
    - **8 大荣誉勋章**：包括「初次邂逅」、「品牌死忠」（连续 20 杯）、「海王品鉴」（15 个品牌）、「清糖苦行僧」（50 杯无糖）等极具人设感的成就。
    - **SSR 高光卡片**：点击已解锁勋章，将唤起基于 `motion/react` 的居中聚焦弹窗，以“高光见证者”相框形式展示解锁成就的关键饮品及其达成日期。

    ### 2. 📅 沉浸式记录与独立滑动布局

    - **大厂级 UI 架构**：彻底摒弃 Web 端传统的整页滚动，采用 `100dvh` 锁死外层 + 上半部分固定 + 下半部分独立滚动的终极移动端布局，彻底解决 iOS 橡皮筋回弹和视差错位 Bug。
    - **动态日历视图**：首页日历支持在“品牌 Logo”与“实拍贴纸”间无感切换，点击日期卡片时，下方的奶茶列表会进行高精度绝对坐标计算，像抽屉一样丝滑、精准地滑跃至屏幕正中央。
    - **三段式沉浸弹窗**：所有的交互弹窗（如添加记录）均采用“头部吸顶 + 内部滚动 + 底部悬浮”的三段式设计，确保无论表单多长，关键的“保存”与“关闭”按钮永远触手可及。
  
    ### 3. 📊 数据可视化与莫兰迪美学
  
    - **高颜值奶茶色板**：摒弃了传统品牌高饱和度、易撞色的辣眼睛色板，重构了一套低饱和度、高明度的“莫兰迪/奶油质感”品牌映射色板（如瑞幸的海盐雾霾蓝、霸王茶姬的乌龙红茶色），视觉体验极其和谐治愈。
    - **满血版时光贴纸盒**：利用 `Framer Motion` 实现了带有物理堆叠感和厚重白边滤镜的“照片墙”。贴纸会随记录增加自动智能微缩，并支持悬浮放大交互。
    - **智能排版防遮挡**：运用 Flexbox 高级收缩魔法 (`min-w-0`, `truncate`) 与安全间距计算，让长文本（如日期与称号）在极小屏幕下也能优雅截断，绝不发生元素重叠。

    ### 4. 🧾 “电影级”分享引擎
  
    - **三合一分享模式**：支持“单杯精致小票”、“周期统计长单”以及“Spotify 风格 Wrapped 年度海报”。
    - **高清导出**：基于 `html-to-image` 的多倍采样率渲染，确保分享到朋友圈的每一张海报都清晰锐利，支持原生 `navigator.share` 唤起系统底层分享。

    ## 🛠️ 技术深度与性能优化

    ### 1. 🚀 极致渲染与性能降级引擎
  
    - **双擎物理动画**：在“贴纸墙”渲染中引入了算力监控理念。当杯数较少时，启用拥有极佳 Q 弹手感的 `Spring` 物理引擎；当杯数面临爆炸（如年度视图上百杯）时，系统自动降级为 `Tween` 平滑过渡，并开启 `will-change-transform` GPU 硬件加速，确保几百张贴纸倾泻而下时依然保持 60fps 的绝对丝滑。
    - **边缘节点与 CDN 优化**：针对海外服务器（如 Cloudflare）部署，对静态图片加载实行了严格的 URL 强制编码 (`encodeURI`) 和异步解码 (`decoding="async"`)，彻底消灭了多图并发时的阻塞残影现象。
    - **静默图片压缩 (WebP)**：通过 HTML5 `Canvas` 在前端静默将原图压缩至 100KB 以内的 `WebP` 格式，大幅减轻存储压力。设置页还内置了“空间瘦身”功能，可一键对存量的沉重 Base64 历史数据进行批量洗刷。

    ### 2. 💽 离线优先架构
  
    - **localforage 存储**：摒弃传统的 `localStorage`，采用 `localforage` 构建底层异步数据库，支持海量图片数据的稳定离线存储。
    - **数据孤岛救援**：提供完整的 `.json` 格式数据导出（备份）与导入（恢复）功能，无惧清缓存或更换设备。

    ### 3. ✨ 物理级微交互
  
    - **触觉反馈 (Haptics)**：深度接入 `navigator.vibrate`，在点击成就、滑动定位、保存记录等关键节点提供轻、中、重三级真实的物理震动反馈。
    - **动态字号系统**：支持“小、中、大”三档字号切换，动态修改 HTML 根元素 `font-size`，全局驱动 Tailwind 响应式布局。
