# 🥤 Sugar Ultra (糖人App) - 极客范的奶茶手账与自律管家

Sugar Ultra 是一款专为奶茶与咖啡爱好者打造的沉浸式生活记录工具。它不仅仅是一个高颜值的账单本，更是一个融合了智能算法、物理微交互与情绪价值的“赛博手账”。目前，项目已演进为**支持 PWA 与 Capacitor 混合打包**的成熟单页应用 (SPA)，拥有跨平台的原生 App 级极致交互与完全闭环的离线优先架构。

## ✨ 核心功能特性

### 1. 🏆 主机级成就系统与多巴胺引擎 (Epic Update!)

- **多巴胺打卡高潮**：引入 `canvas-confetti` 全屏爆破引擎与 Framer Motion 老虎机数字翻滚动效。当用户连续打卡触发特定里程碑（如 3天、7天）时，徽章注水进度条瞬间暴涨，伴随满屏奶茶色碎纸爆破与主机级双段震动，将用户的沉没成本转化为极强的情绪正反馈。
- **Xbox / PS 级悬浮横幅**：彻底重构了系统的 Toast 提示与成就解锁弹窗。采用暗黑流光底板与深浅色动态自适应逻辑，长篇的“毒舌语录”或“高光成就”会以充满主机游戏质感的横幅从屏幕顶部“Duang”地弹射坠落。
- **时光倒流与高光相框**：智能算法严格按真实饮用日期正序重排触发成就。点击解锁的勋章，将唤起基于 motion 的居中聚焦弹窗，以带有神圣光晕的“高光见证者”相框形式，展示那杯至关重要的饮品。

### 2. 🎨 变量级全局主题与莫兰迪美学

- **CSS `color-mix` 动态引擎**：抛弃了 Tailwind 的硬编码限制，在底层注入了前沿的 CSS 变量主题引擎。只需切换一个十六进制色号，系统会利用 `color-mix` 自动计算出全局的柔和背景、高亮边框、流光渐变与呼吸投影，实现一秒无痛全局换肤。
- **高颜值专属色板**：重构了一套低饱和度、高明度的“莫兰迪/奶油质感”品牌映射色板（如瑞幸的海盐雾霾蓝、霸王茶姬的乌龙红茶色），拒绝辣眼睛的高饱和度数据图表，让数据统计界面极度和谐治愈。
- **满血版时光贴纸盒**：利用 Framer Motion 实现了带有物理堆叠感和厚重白边滤镜的“照片墙”。贴纸会随记录增加自动智能微缩，并支持悬浮穿透放大交互。

### 3. 📅 全面沉浸布局与变色龙状态栏

- **变色龙状态栏伪装术**：为了打破原生系统对 PWA 的沉浸式限制，编写了延迟一帧吸取 DOM 真实背景色的 JS 脚本，动态劫持并覆盖 `<meta name="theme-color">`，让系统状态栏与 App 页面背景实现“0色差像素级融合”，达到真正的无边框 Edge-to-Edge 沉浸感。
- **柔性安全滚动包裹**：彻底解决移动端“长内容顶破屏幕”痛点。所有的弹窗与长条小票均采用 `overflow-y-auto` 配合 `min-h-full` 柔性包裹层，确保内容少时绝对居中，内容爆炸时（如喝了50杯的超长小票）丝滑滚动且底部按钮永不遮挡。
- **大厂级 UI 架构**：采用 `100dvh` 锁死外层 + 上下独立滚动的终极移动端布局，根治 iOS 橡皮筋回弹 Bug。支持动态字体缩放 (Font Scale) 与卡片密度 (Card Density) 切换，满足不同设备的阅读偏好。

### 4. 🧾 “电影级”分享引擎与自律管家

- **三合一高清分享**：支持“单杯手账贴纸小票”、“周期统计长账单”以及“Spotify 风格 Wrapped 年度海报”。基于 `html-to-image` 的多倍采样率渲染，加上底部的拟物锯齿与条形码，让分享到朋友圈的每一张海报都极具实体质感。
- **无痛自律模式**：设置面板引入轻量级“预算与杯数限制”。进度条利用红、橙、金三色和生动的微文案，对即将超标或已超标的状态进行直观预警（如“破产预警”）。

## 🛠️ 技术深度与性能优化

1. **🚀 极致渲染与性能降级引擎**
   - **双擎物理动画**：贴纸墙引入算力监控理念。数量少时启用 Q 弹的 Spring 引擎；百杯爆炸时自动降级为 Tween 平滑过渡，并开启 `will-change-transform` GPU 硬件加速，确保几百张贴纸倾泻而下时依然保持 60fps 的绝对丝滑。
   - **静默图片压缩洗刷**：通过 HTML5 Canvas 在前端静默将原图压缩至极小的 WebP 格式。内置“空间瘦身”算法，可一键遍历并压缩历史遗留的庞大 Base64 数据，守护手机存储空间。
2. **💽 混合跨平台与离线优先架构**
   - **Capacitor 原生支持**：深度适配 Capacitor 环境（引入 `@capacitor/preferences`），修复了原生 WebView 下相机/相册调用的权限逻辑。
   - **异步底层存储**：采用 `localforage` 构建底层异步数据库，支持海量图片数据的稳定离线读写。提供完整的 `.json` 格式数据冷备份与恢复，无惧清缓存或更换设备。
3. **✨ 物理级感官共鸣**
   - **动态触觉矩阵 (Haptics)**：深度接入 `navigator.vibrate`，针对不同操作赋予灵魂。例如轻点日历的轻巧 `15ms`、删除记录的厚重 `50ms`，以及触发高级成就时的“Xbox 主机级两段式酥麻长震动” `[100, 60, 200]`。

## 💻 技术栈

- **核心框架**: Next.js 14+ (React 18+) / 混合打包方案: Capacitor
- **样式方案**: TailwindCSS / CSS Color-mix 动态引擎
- **动画引擎**: framer-motion / canvas-confetti
- **数据持久化**: localforage
- **截图引擎**: html-to-image
- **图标库**: Lucide React
