# 🥤 Sugar Ultra (糖人App) - 专属奶茶记录与自律管家

**Sugar Ultra** 是一款专为奶茶、咖啡爱好者打造的沉浸式生活记录工具。它不仅是一个高颜值的账单本，更是一个充满情绪价值的“赛博手账”和自律管家。目前，项目已经演进为一个拥有原生 App 质感、完整业务闭环以及极高数据安全性的成熟单页应用（SPA）。

---

## ✨ 核心功能特性 (Core Features)

### 1. 📅 沉浸式记录与日历墙
* **极简添加流**：支持自定义日期（补签）、品牌智能匹配、饮品名称、价格、容量、温度和甜度的全方位记录。
* **实拍贴纸压缩**：支持用户上传奶茶实拍图，或默认使用各大品牌的专属 Logo。
* **日历视图切换**：首页提供直观的月度日历，可自由切换“品牌 Logo”或“实拍奶茶贴纸”作为打卡标记，并支持“周日”或“周一”作为每周起始日的个性化切换。

### 2. 📊 多维数据统计与贴纸墙 (Stats & Visual Shelf)
* **时光贴纸盒**：打破传统的列表展示，引入带有物理重叠感和白色发光描边的“手账贴纸墙”。所有喝过的奶茶像拍立得一样交叠散落，鼠标悬浮时丝滑放大。
* **三维统计周期**：一键切换【周】、【月】、【年】视图。
* **图表可视化**：
    * **品牌占比 (Donut Chart)**：直观展示各大品牌的“杯数”与“花费”占比，内置十余个主流品牌的专属 UI 配色（如瑞幸蓝、霸王茶姬红等）。
    * **趋势柱状图**：支持查看每日、每周或每月的饮茶趋势。

### 3. 🧾 “电影级”分享小票 (Receipt Generator)
* **精美网格排版**：一键将统计数据或单杯奶茶生成极具设计感的实体购物小票长图。
* **趣味情绪价值**：小票底部带有动态计算的“成就印章”（如：*清糖佛子*、*奶茶土匪*、*老喝家*），以及“多巴胺附加税已免除”等趣味彩蛋。
* **跨端分享**：基于 `html-to-image` 完美解决跨端截图问题，支持直接调用原生 `navigator.share` 或保存至相册。

### 4. 🎯 自律模式 (Discipline Mode)
* **目标管理**：允许用户设置“周预算”、“周杯数”、“月预算”、“月杯数”红线。
* **情绪进度条**：统计卡片内置动态变色进度条（安全色 -> 警告橙 -> 超标红），化被动记录为主动管理。

### 5. 🔍 全局历史搜索与时光轴 (Timeline Search)
* **高级时光轴 UI**：在首页右上角提供全局搜索入口，以垂直时间轴（Timeline）的形式展示所有历史记录，辅以品牌专属色的视觉锚点。
* **模糊检索**：支持对品牌或饮品名称的实时模糊过滤，一键点击即可追溯/修改历史订单。

## 🛠️ 高级体验与底层性能 (Advanced & Performance)

### 1. 💽 本地化与数据安全
* **彻底的离线优先**：采用 `localforage` 构建底层数据库，突破传统 `localStorage` 的存储限制。
* **数据孤岛救援**：提供完整的 `.json` 格式数据**导出（备份）**与**导入（恢复）**功能，彻底打消换手机或清缓存导致数据丢失的顾虑。

### 2. 🚀 极致性能优化
* **静默图片压缩 (WebP)**：通过 HTML5 `Canvas` 在用户选择照片的瞬间，将动辄 5MB-10MB 的原图静默压缩为 100KB 以内的 `WebP` 格式（完美保留透明度）。
* **一键空间瘦身**：设置页提供 `🧹 空间瘦身` 按钮，利用后台协程对过往庞大的历史 Base64 脏数据进行洗刷与体积压缩，保证 App 极速运行。
* **浮点数精度修复**：底层封装了精确的金额累加逻辑，杜绝了 JS 经典的 `0.1 + 0.2` 小数点溢出 Bug。

### 3. ✨ 物理级微交互
* **触觉反馈 (Haptics)**：全面接入 `navigator.vibrate`，在开启弹窗、切换视图、导出数据等核心场景提供“轻、中、重”三级物理震动反馈。
* **优雅的提示条 (Toast)**：完全摒弃原生 `alert`，使用 Framer Motion 打造了仿 Apple 风格的全局悬浮 Toast，状态反馈平滑自然。

### 4. 📱 PWA 就绪 (Progressive Web App)
* 界面完全基于移动端沉浸式设计（隐藏滚动条、全屏弹窗、底部常驻导航）。随时可以通过配置 `manifest.json` 添加至手机主屏幕，获得等同于原生 App 的全屏使用体验。

## 💻 技术栈 (Tech Stack)
* **核心框架**: React (Next.js)
* **样式方案**: TailwindCSS
* **动画引擎**: Framer Motion
* **图标库**: Lucide React
* **数据存储**: localforage
* **截图引擎**: html-to-image / html2canvas
