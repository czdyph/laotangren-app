# 🥤 Sugar Ultra (老糖人) - 极客范的奶茶手账与自律管家

Sugar Ultra 是一款专为奶茶与咖啡爱好者打造的沉浸式生活记录工具。它不仅仅是一个高颜值的账单本，更是一个融合了智能算法、物理微交互与情绪价值的“赛博手账”。历经深度的底层架构重构，项目现已演进为**支持 PWA 与 Capacitor 混合打包**的满血版单页应用 (SPA)，拥有跨平台的原生 App 级极致交互、大厂级状态管理与极简的性能消耗。

## ✨ 核心交互体验

### 1. 🏆 主机级成就系统与多巴胺引擎
- **多巴胺打卡高潮**：引入 `canvas-confetti` 全屏爆破引擎与 Framer Motion 老虎机数字翻滚动效。连续打卡触发特定里程碑时，徽章注水进度条瞬间暴涨，伴随主机级双段震动，将用户的沉没成本转化为极强的情绪正反馈。
- **Xbox / PS 级悬浮横幅**：重构了系统的 Toast 提示与成就解锁弹窗。长篇的“毒舌语录”或“高光成就”会以充满主机游戏质感的横幅，从屏幕顶部带有弹簧物理效果地坠落。
- **高光相框与时光倒流**：智能算法按真实饮用日期正序重排成就。点击解锁勋章，唤起基于 motion 的居中聚焦弹窗，以带有神圣光晕的“高光见证者”相框形式展示关键饮品。

### 2. 📱 完美重塑的原生手势与防打断机制 (New!)
- **双重降维返回防线**：深度接入 `@capacitor/app`，全面接管 Android 系统的物理返回键与侧边滑动返回。按照视觉 Z 轴层级，精准做到“先关弹窗、再退页面、最后挂起”，彻底告别误触闪退。
- **丝滑右滑物理关闭 (Swipe to Dismiss)**：为小票、年度海报等全屏视图引入 `drag="x"` 物理拖拽手势。支持大拇指顺滑向右拖拽，带有极具真实感的弹性阻尼与速度判定，松手即刻飞出屏幕，赋予 App 顶级的原生跟手感。

### 3. 🎨 变量级全局主题与莫兰迪美学
- **CSS `color-mix` 动态引擎**：打破 Tailwind 硬编码限制，底层注入 CSS 变量主题引擎。只需切换色号，系统自动利用 `color-mix` 计算柔和背景、流光渐变与呼吸投影，实现无痛全局换肤。
- **高颜值专属色板**：提取各大茶饮品牌的“莫兰迪/奶油质感”品牌映射色板（如海盐雾霾蓝、乌龙红茶色），拒绝辣眼睛的高饱和度，让数据图表极度和谐治愈。

### 4. 🧾 “电影级”分享引擎与自律管家
- **三合一高清分享**：支持“单杯手账贴纸小票”、“周期统计长账单”以及“Spotify 风格 Wrapped 年度海报”。基于 `html-to-image` 的多倍采样率渲染，保留拟物锯齿与条形码，极具实体质感。
- **无痛自律模式**：引入轻量级“预算与杯数限制”。进度条利用红、橙、金三色和生动的微文案，对即将超标或已超标的状态进行直观预警。

## 🛠️ 史诗级架构重构与性能榨取 (v2.0 核心升级)

### 1. 💽 冷热数据分离与原生物理沙盒 (零 OOM 架构)
- **告别 Base64 内存炸弹**：引入 Capacitor `Filesystem`，重写图片存储逻辑。用户的奶茶照片将以纯粹的 `.jpg/.png` 文件直接存入操作系统的**应用私有数据沙盒 (Directory.Data)** 中。
- **极速状态树**：JSON 数据库中仅保留极短的本地图片 URI 指针（如 `file:///data/user/0/...`）。即使积攒上万条记录，App 启动时的内存占用也近乎为 0，彻底根治低端安卓机的白屏与 OOM (内存溢出) 崩溃。

### 2. 🧠 Zustand 状态下沉与逻辑解耦
- **消灭巨石组件 (Monolith)**：全面引入 `zustand` 状态管理，重构 `store/useStore.ts`。将原先堆积在入口页面的冗长 `useState`、持久化逻辑、设置同步逻辑全部抽离至中央数据车站。
- **极致解耦的 Hooks 架构**：拆分出负责操作系统视觉映射的 `useImmersiveStatusBar`、负责外部交互与文件流的 `useExportActions`，让 UI 组件完全回归纯粹的排版与渲染。

### 3. 🚀 虚拟滚动与智能渲染降级
- **大厂级无限列表**：历史记录页全面接入 `react-virtuoso` 虚拟滚动引擎。不论用户拥有 20 还是 20,000 杯记录，DOM 树上永远只渲染当前屏幕可见的十几个节点，滑动帧数死锁 60fps。
- **GPU 智能降级与懒加载**：在年度统计的“贴纸墙”中加入算力监控。一旦检测到海量数据（如年度 300 杯），主动剥离极其耗费 GPU 的弹簧阻尼运算 (`type: 'spring'`)，降级为丝滑的缓动渐显；同时配合原生 `loading="lazy"` 与 `decoding="async"`，让屏幕外的图片彻底不参与内存解码。

### 4. 🛡️ 移动端防爆排版系统
- 针对中文排版的特殊性，在所有卡片层级加入了 `min-w-0`、`break-all` 与 `line-clamp-2` 的“终极防御” CSS 组合拳。彻底解决了移动端 Flex 布局下超长饮品名（如备注乱填）撑爆屏幕、导致横向滚动溢出、挤飞价格标签的史诗级暗坑。

## 💻 技术栈

- **核心框架**: Next.js 14+ (React 18+)
- **混合打包 & 底层桥接**: Capacitor 6+ (`@capacitor/app`, `@capacitor/filesystem`, `@capacitor/preferences`)
- **状态管理**: Zustand
- **无限列表引擎**: React Virtuoso
- **样式方案**: TailwindCSS / CSS Color-mix 动态引擎
- **动画引擎**: framer-motion / canvas-confetti
- **数据持久化**: localforage
- **截图引擎**: html-to-image
- **图标库**: Lucide React
